# 04 · 训练与验证（train.py）

## 1. 数据流一览

```
data_dir(D:\CV\custom_muti)
   │  build_loaders()
   ├─ 有标签 train_lb  (labeled_ratio)          → (x_lb, y_lb)   [B,C] 0/1
   ├─ 无标签 train_ulb (1-labeled_ratio)        → (x_ulb_w, x_ulb_s)
   ├─ 验证 val                                 → (x, y)
   └─ (可选) 测试 test
                │
   构建 ML-GCN(backbone,gcn_t,adj_file,inp)  ── 构建 loss(asl|bce) ── 构建一致性损失(BCE)
                │
        FreeMatchMultiLabel（阈值/EMA/熵正则/一致性）
                │
       AMP 训练循环 ── 定期验证(mAP) ── 早停(patience) ── 保存 best/final
```

## 2. 命令行示例

### 2.1 用配置文件训练
```bash
python train.py --c configs/freematch_mlgcn_resnet50.yaml
```

### 2.2 用命令行覆盖部分超参数
```bash
python train.py --c configs/freematch_mlgcn_resnet50.yaml \
    --overwrite "labeled_ratio=0.1 lr=0.003 batch_size=4 img_size=384"
```
> 优先级：**命令行 > YAML > 默认**。

### 2.3 直接在命令行给定全部关键参数（不写 YAML）
```bash
python train.py \
  --data_dir D:/CV/custom_muti \
  --num_classes 15 \
  --labeled_ratio 0.2 --split_mode by_prefix \
  --backbone resnet50 --variant gcn --gcn_t 0.4 \
  --loss asl --asl_gamma_neg 4.0 --asl_gamma_pos 1.0 --asl_clip 0.05 \
  --T 0.5 --ema_p 0.999 --use_ema_teacher true --lambda_u 1.0 --lambda_e 0.005 \
  --img_size 224 --batch_size 8 --uratio 3 --epochs 120 \
  --lr 0.005 --optim SGD --weight_decay 5e-4 --amp true \
  --patience 15 --save_name freematch_mlgcn_resnet50
```

### 2.4 恢复训练
```bash
python train.py --c configs/freematch_mlgcn_resnet50.yaml \
    --resume true --load_path outputs/freematch_mlgcn_resnet50/best.pth
```

## 3. 关键超参数说明

| 类别 | 参数 | 默认 | 说明 |
|------|------|------|------|
| 数据 | `labeled_ratio` | 0.2 | 有标签比例，越小无标签越多 |
|      | `split_mode` | `by_prefix` | 按文件名前缀分组内切分 |
| 模型 | `backbone` | `resnet50` | 见 `docs/03`；4GB 建议 50/34 |
|      | `variant` | `gcn` | `gcn`/`gap`/`gmp`（消融基线用后两者） |
|      | `gcn_t` | 0.4 | 邻接矩阵二值化阈值 |
| 损失 | `loss` | `asl` | `asl`/`bce`；`bce` 为消融 |
|      | `asl_gamma_neg/pos/clip` | 4/1/0.05 | ASL 参数 |
|      | `use_class_balancing` | true | 稀有类正样本加权 |
| FreeMatch | `T` | 0.5 | 软伪标签锐化温度 |
|      | `hard_label` | false | true=硬二值伪标签 |
|      | `ema_p` | 0.999 | 阈值 EMA 动量 |
|      | `ema_m` | 0.999 | 权重 EMA 动量 |
|      | `use_ema_teacher` | true | 用 EMA 教师生成伪标签 |
|      | `lambda_u` | 1.0 | 一致性损失权重 |
|      | `lambda_e` | 0.005 | 熵正则权重 |
| 训练 | `img_size` | 224 | 分辨率 |
|      | `batch_size`/`uratio` | 8 / 3 | 无标签批次 = `batch_size*uratio` |
|      | `epochs` | 120 | 最大 epoch |
|      | `num_eval_iter` | 500 | 每 N 步验证一次 |
|      | `amp` | true | 混合精度 |
| 优化 | `optim`/`lr` | SGD / 0.005 | SGD 带 Nesterov |
|      | `weight_decay` | 5e-4 | 正则 |
|      | `layer_decay` | 0.5 | backbone 层的学习率衰减倍率 |
| 早停 | `patience` | 15 | 验证 mAP 连续 N 次不升则停 |
|      | `metric` | `eval/mAP` | 监控指标 |

## 4. 早停机制
- 每 `num_eval_iter` 步在验证集上算 `eval/mAP`（用 EMA 模型）。
- 若 mAP 刷新记录 → 保存 `best.pth`，`no_improve=0`；否则 `no_improve+=1`。
- 当 `no_improve ≥ patience` → 停止并跳出；最终评估重新加载 `best.pth`。

## 5. 输出产物（`save_dir/save_name/`）
| 文件 | 内容 |
|------|------|
| `best.pth` | 最佳验证模型（`algorithm` 含 model/ema_model/p_model/label_hist/time_p + optimizer + scheduler + args） |
| `final.pth` | 训练结束时保存（含 `val_metrics` 字典） |
| `*metrics_val.csv` | 由 `evaluate.py` 生成 |

## 6. 4 GB 显存调参建议
| 场景 | 建议 |
|------|------|
| 默认（224×224） | `batch_size=8`、`eval_batch_size=16`、`amp=true`、`num_workers=4` |
| 384×384 | `freematch_mlgcn_resnet50_384.yaml`：`batch_size=4`、`eval_batch_size=8` |
| 想更大 backbone | 使用 `resnet34` 并减小 `batch_size`；不建议 4GB 上跑 resnet101 |
| 显存不足 | 减小 `uratio`、`eval_batch_size`、`img_size`，或关 `RandomGrayscale` |

## 7. 评估
```bash
# 验证集
python evaluate.py --checkpoint outputs/freematch_mlgcn_resnet50/best.pth --phase val
# 测试集（需要在参数里指定 test_phase 或在 evaluate 里 --phase test）
python evaluate.py --checkpoint outputs/freematch_mlgcn_resnet50/best.pth --phase test
```
输出含 `mAP`、`macro/micro-F1`、`macro/micro-P/R`、`hamming`，以及逐类 AP/Precision/Recall/正样本数。
