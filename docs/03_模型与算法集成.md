# 03 · 模型与算法集成（ML-GCN + ASL + FreeMatch）

本节说明三库核心代码的**提取 / 集成**方式，以及如何解决接口兼容与依赖冲突。
代码位于 `mlgcn/`（models / losses / freematch）与 `data/`（数据集）。

## 1. 集成架构（为什么"提取核心 + 自建框架"）
直接 `pip install` 三库会带来大量冲突（semilearn 依赖 torch>=1.x、wandb/aim/多机，ASL 依赖 tresnet 与
`--pretrained` API，ML-GCN 与 torchvision 版本耦合）。因此本项目**不安装三个库**，只把它们的核心逻辑
`vendor` 进独立模块，统一接口，各自无交叉依赖：

```
mlgcn/
├── models.py     ← 来自 ML-GCN（GCNResnet / GraphConvolution / gen_A / gen_adj）
├── losses.py     ← 来自 ASL（AsymmetricLoss / AsymmetricLossSoft）
├── freematch.py  ← 来自 USB/FreeMatch（阈值更新 / 掩码 / 熵正则 / EMA teacher）
└── metrics.py    ← 通用评估（mAP / F1 / hamming）
data/custom_dataset.py  ← 来自已有 custom_semi.py（MultiLabelDataset + collate_fn）
```

只需三个**核心张量接口**统一即可拼装：
- 模型：`model(x) -> logits[B,C]`（本项目统一返回张量，不做字典输出）。
- 损失：`criterion(logits, target) -> scalar 或 [B,C]`。
- 数据：`(x_lb, y_lb)` 与 `(x_ulb_w, x_ulb_s)`。

## 2. 提取 ML-GCN（`mlgcn/models.py`）

### 2.1 关键实现（保留论文原义）
- `GraphConvolution`：GCN 层，`weight` 均匀初始化，可选 bias。
- `GCNResnet`：`ResNet 特征 -> GMP -> matmul(feature, GCN(label_embedding))`。
  - 邻接矩阵 = `gen_A(num_classes, t, adj_file)`（二值化 + 重加权）+ `gen_adj`（对称归一化），
    以 `buffer` **预计算并冻结**。
  - `inp` = GloVe 词向量 `[C, 300]`，作为**可学习**标签嵌入初值。
- 论文对比如：`pooling=AdaptiveMaxPool2d`（GMP，ML-GCN 用 GMP 而非 GAP）。

### 2.2 与您数据的对接
```python
from mlgcn import build_model, load_class_embeddings
inp = load_class_embeddings(r"D:\CV\custom_muti\custom_glove_word2vec.pkl")  # [15,300]
model = build_model(num_classes=15, backbone="resnet50", variant="gcn",
                    pretrained=True, t=0.4,
                    adj_file=r"D:\CV\custom_muti\custom_adj.pkl", inp=inp)
```

### 2.3 可配置性（相对原实现的增强）
- `backbone ∈ {resnet18,34,50,101}`：GCN 输出维度自动对齐到 backbone 特征维度。
- `variant ∈ {gcn, gap, gmp}`：`gcn`=ML-GCN；`gap/gmp`=无图的线性头**消融基线**。

## 3. 集成 ASL（`mlgcn/losses.py`）

| 损失 | 用途 | 关键参数 |
|------|------|----------|
| `AsymmetricLoss` | **有标签**监督损失 | `gamma_neg`(默认4)、`gamma_pos`(默认1)、`clip`(默认0.05)、`reduction='none'` |
| `AsymmetricLossSoft` | **无标签**一致性（软伪标签） | `gamma_neg=2, gamma_pos=0, clip=0`（**不做硬裁剪**） |
| `build_loss('bce')` | 消融：标准 BCE | —— |

- **为什么无标签一律用 `AsymmetricLossSoft`/BCE 而非硬 ASL**：软伪标签中 `p=0.05` 未必是**真负样本**，
  硬裁剪会把这些类别当负样本硬筛掉，抑制正类学习。
- 两版都在 `forward` 内强制 `float()` 规避 AMP/float16 下 `log(0)` 导致的 NaN。

## 4. 提取 FreeMatch（`mlgcn/freematch.py`）

### 4.1 单标签 → 多标签的三个改造点
1. **`sigmoid` 替代 `softmax`**：多标签每类独立概率。
2. **每类阈值**替代每样本阈值：`thresh[c] = time_p · (p_model[c]/max(p_model))`，再 `clamp[0.25,0.90]`；
   掩码为 `[U,C]` 布尔张量，逐 `(样本,类)` 判断。
3. **`[U,C]` 掩码的一致性损失**：`BCE(logits_s, pseudo) * mask` 求和 / `mask.sum()`。

### 4.2 状态与更新（均为多标签版）
- `p_model`：`EMA(p_model, mean_c(probs_ulb))`。
- `label_hist`：由 `(probs_ulb > 0.5)` 的每类计数归一化后 EMA。
- `time_p`：`EMA(time_p, quantile(probs, 0.9))`，再 `clamp[0.6,0.95]`。
- 熵正则：`confidence_loss + 0.05 · fairness_loss`（详见 `entropy_loss`）。

### 4.3 教师模型
- `use_ema_teacher=True`：用 EMA teacher 在**弱增强**上生成伪标签（更稳定），学生在**强增强**上对其一致性。
- 评估默认用 EMA 模型（`algo.evaluate(use_ema=True)`）。

### 4.4 与训练脚本的接口
```python
algo = FreeMatchMultiLabel(model, num_classes, criterion, consistency_criterion,
                           use_amp=args.amp, device=...)
log_dict, loss = algo.train_step(x_lb, y_lb, x_ulb_w, x_ulb_s)  # 半监督
log_dict, loss = algo.sup_train_step(x_lb, y_lb)                # 全监督（无无标签时）
metrics, logits, targets = algo.evaluate(val_loader, use_ema=True)
```

## 5. 依赖冲突的解决办法（汇总）
| 冲突点 | 解决 |
|--------|------|
| torchvision `pretrained=` 弃用 | 用 `weights=` 新 API（`models._backbone`） |
| torch.load 默认 `weights_only=True` 拒绝 numpy 标量 | 自生成 checkpoint 一律 `torch.load(..., weights_only=False)`，且 `compute_metrics` 把指标转成原生 `float` |
| AMP API 变更 | 用 `torch.amp.autocast` / `torch.amp.GradScaler` |
| `RandomSampler` 在空无标签数据集报错 | `labeled_ratio=1.0` 时 `shuffle=False`（见 `build_loaders`） |
| 无标签时 `sigmoid` 数值下溢 | `forward`/`entropy_loss` 强制 float32，`clamp` 小量 |
