|--------|----|
| 类别数 | **15** |

> **关键结论**：训练集是**全标注**的。要做半监督，必须把一部分训练样本的**标签隐藏**，作为"无标签"数据。
> 这正是 `MultiLabelDataset` 用 `labeled_ratio` 实现的标准做法。

### 1.3 三种标注/嵌入格式
- **`category.json`**：`{类名: 索引}`，索引 0~14。
- **`*_anno.json`**：`{file_name, labels:[索引...]}`，`labels` 为**正类索引列表**。
- **`custom_adj.pkl`**：`pickle` 字典，键 `P`，值 `[15,15]` 的条件概率。
- **`custom_glove_word2vec.pkl`**：`pickle` → `numpy[15,300] float32`。

## 2. 与三个库所需格式的对应与适配

| 库 | 期望输入 | 您的数据 | 适配方式 |
|----|----------|----------|----------|
| **ML-GCN** | 每图多标签向量（0/1）、邻接矩阵 `custom_adj`、`word2vec` 嵌入 | 已提供 | 由 `MultiLabelDataset` 把 `labels` 索引转成 **`{0,1}` 二进制向量**；`GCNResnet` 直接接收 `adj_file` 与 `inp` |
| **ASL** | `logits[B,C]` + 二值目标 `[B,C]`（0/1） | 同上 | 目标向量即满足 |
| **FreeMatch (USB)** | 有标签 `(x_lb, y_lb)`、无标签 `(x_ulb_w, x_ulb_s)` 双视图 | 需自行构建 | `MultiLabelDataset` 对有标签返回 `(img, target)`，对无标签返回 `(weak, strong)`；`collate_fn` 分别打包 |

> **建议**：尽量不改动您的数据文件，仅在 `data/custom_dataset.py` 中定义"如何读取 + 如何隐藏标签"即可。

## 3. `data/custom_dataset.py`（数据加载器）

### 3.1 `MultiLabelDataset`
- **`labeled_ratio`**（默认 0.2）：训练集中保留标签的比例。
- **`split_mode`**：
  - `random`：整体打乱后按比例切分（简单）。
  - `by_prefix`（推荐）：按文件名首个 `-` 前缀（如 `01`/`02`…）**分组内**按比例切分，
    保证每个来源都有有/无标签样本，避免某一来源全部落入同一侧。
- **`is_unlabeled`**：为 `True` 时返回弱/强增强**双视图**（无标签）；为 `False` 时返回 `(img, target)`。
- 标签编码：`labels` 索引 → `np.zeros(C)`，置正类为 `1.0`（**0/1**，供 ASL / BCE）。
- 图像统一转 `RGB`、读取时 `assert` 存在性、失败的路径给出明确报错。

### 3.2 `collate_fn`
根据 `batch[0]` 的元素结构自动区分打包：
- 无标签（两个 `[3,H,W]` 张量）→ `(weak[B,3,H,W], strong[B,3,H,W])`。
- 有标签 / 验证（`img + 1D target`）→ `(images[B,3,H,W], targets[B,C])`。

### 3.3 自测
```bash
python -m data.custom_dataset --data_dir D:/CV/custom_muti --img_size 224 --ratio 0.2
```
预期输出（示例）：`labeled=439(19.9%)`, `unlabeled=1770(80.1%)`, `val=634`, `test=317`，并打印单个样本的正类/图像形状。

## 4. 若将来有独立"未标注"图片
若您日后提供真正未标注的图片目录，只需：
- 在 `MultiLabelDataset` 增加一个 `unlabeled_dir`/`unlabeled_anno` 分支，对 `is_unlabeled` 直接读取该目录而不做标签隐藏；
- `labeled_ratio` 逻辑则只作用于"有标注图"。
（当前版本为**标准 SSL 隐藏标签**协议，无需额外数据。）
