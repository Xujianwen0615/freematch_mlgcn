# 05 · 消融实验与基准对比

## 1. 目的

回答两个核心问题，从而论证所提方法（**FreeMatch + ML-GCN + ASL**）的有效性：

1. **半监督是否有效**？相对"只用有标签"的全监督基线，mAP 提升多少？
2. **ML-GCN 与 ASL 各自的作用**？去掉其中一个，指标如何变化？

## 2. 实验矩阵（`configs/ablation/` + `run_experiments.py`）

> 建议**固定** `seed`、`backbone=resnet50`、`img_size=224`、`epochs=120`，仅改变关注的变量，保证对照公平。

| 编号            | 实验                                           | `labeled_ratio` | `loss` | `variant` | `lambda_u` | 目的                         |
| ------------- | -------------------------------------------- | --------------- | ------ | --------- | ---------- | -------------------------- |
| **A**         | 全监督 ML-GCN + BCE                             | 1.0             | `bce`  | `gcn`     | 0          | 最朴素**基线**                  |
| **B**         | 全监督 ML-GCN + ASL | 1.0             | `asl`  | `gcn`     | 0          | 验证 ASL 单独作用（相对 A）          |
| **H**         | **弱监督** ML-GCN+ASL（只用 20% 标签，**不用无标签**） | 0.2 | `asl`  | `gcn`     | 0          | **关键基线**：同一批 20% 标签、无半监督时的 mAP（相对 D） |
| **C**         | FreeMatch + ML-GCN + **BCE**                 | 0.2             | `bce`  | `gcn`     | 1.0        | 验证 ASL 在半监督下的作用（相对 D）      |
| **D**         | **完整方法** FreeMatch+ML-GCN+ASL                | 0.2             | `asl`  | `gcn`     | 1.0        | 主方法                        |
| **E**         | 无图（GAP） + ASL + FreeMatch                    | 0.2             | `asl`  | `gap`     | 1.0        | 验证 **ML-GCN 图结构**的作用（相对 D） |
| **F**         | 无 GCN 头（GMP） + ASL + FreeMatch               | 0.2             | `asl`  | `gmp`     | 1.0        | 验证 **GCN 头**的作用（相对 D）      |
| **G_ratio_X** | 完整方法，`labeled_ratio`∈{0.05,0.1,0.2,0.5}      | 变化              | `asl`  | `gcn`     | 1.0        | 研究无标签数据量收益曲线               |

**结论推导逻辑**

- `D vs H`：**半监督增益**（同一批 20% 标签下，加入 FreeMatch 利用剩余 80% 无标签前后对比）。这是最有说服力的主结论。
- `D vs C`：ASL 增益。
- `D vs E/F`：ML-GCN（图结构 / GCN 头）增益。
- `H vs A/B`：**"用更少标签"带来的损失**（100% → 20% 标签）；`H` 是"弱监督"下限。
- `G_ratio_*`：无标签越多是否越好，判断是否值得收集更多无标注数据。

> **注意**：`H` 与 `A/B` 的区别是 `labeled_ratio`（1.0 vs 0.2）；`H` 与 `D` 的区别是 `lambda_u`（0 vs 1.0，即是否利用无标签数据）。三者均为 `variant=gcn` + `loss=asl` + `use_class_balancing=true`。

## 3. 一键运行与汇总

```bash
# 跑全部实验，汇总到 CSV
python run_experiments.py --base configs/freematch_mlgcn_resnet50.yaml --out_csv results_summary.csv

# 只跑某几个
python run_experiments.py --only A,B,D

# 跳过 G_ratio_*（时间有限时）
python run_experiments.py --skip G_ratio_05,G_ratio_10,G_ratio_50

# 只看矩阵不运行
python run_experiments.py --dry
```

`run_experiments.py` 逐实验调用 `train.train(args)`，每个实验结束后汇总 `mAP / macro-F1 / micro-F1 / hamming` 成表格。

## 4. 单独运行某个实验

```bash
python train.py --c configs/ablation/sup_only_mlgcn_bce.yaml
python train.py --c configs/ablation/sup_only_mlgcn_asl.yaml
python train.py --c configs/ablation/sup_partial_mlgcn_asl.yaml   # 弱监督基线（20% 标签、无半监督）
python train.py --c configs/ablation/freematch_mlgcn_bce.yaml
python train.py --c configs/ablation/freematch_resnet50_gap_asl.yaml
python train.py --c configs/ablation/freematch_resnet50_gmp_asl.yaml
```

## 5. 统一评估脚本（`evaluate.py`）

对任一已保存 checkpoint 统一计算并上报指标：

```bash
python evaluate.py --checkpoint outputs/<exp>/best.pth --phase val
python evaluate.py --checkpoint outputs/<exp>/best.pth --phase test
```

`evaluate.py` 读取保存的 `args` 以重建模型与数据，计算：

- **mAP**（mean Average Precision，逐类 AP 的平均，跳过验证集无正类的类）。
- **Macro-F1 / Precision / Recall**（每类权重相同，适合长尾）。
- **Micro-F1 / Precision / Recall**（所有样本-类对权重相同）。
- **Hamming loss**（标签级错误率，越低越好）。
- 逐类 `AP / Precision / Recall / pos_count`。

输出终端报告 + `metrics_<phase>.csv`。

## 6. 报告模板

| 实验                       | mAP | Macro-F1 | Micro-F1 | Hamming | 备注                |
| ------------------------ | --- | -------- | -------- | ------- | ----------------- |
| A 全监督+BCE                |     |          |          |         | 基线                |
| B 全监督+ASL                |     |          |          |         | ASL 增益 = B−A      |
| H 弱监督+ASL（20% 标签）      |     |          |          |         | **半监督增益 = D−H**（主结论） |
| C SSL+BCE                |     |          |          |         |                   |
| D SSL+ASL（主）             |     |          |          |         | ASL 在半监督下增益 = D−C |
| E GAP                    |     |          |          |         | ML-GCN 图增益 = D−E  |
| F GMP                    |     |          |          |         | GCN 头增益 = D−F     |
| G 0.05 / 0.1 / 0.2 / 0.5 |     |          |          |         | 无标签量收益            |

> 提示：在**有标签有限**时半监督收益最明显（`labeled_ratio` 低 → mAP 提升大）；有标签充足（0.5/1.0）时
> 半监督收益会被稀释，可据此判断是否需要收集更多无标注数据。

## 7. 注意事项

- 不同实验应**用同一 `seed`** 以降低随机性干扰（默认 42）。
- `labeled_ratio=1.0` 时无无标签数据，`train.py` 自动切换为**全监督训练路径**（`lambda_u=0`）。
- 4 GB 显存下若 OOM，统一调小 `batch_size` / `img_size`，保持**同组实验一致**再对比。
